# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues or pull requests.

To report a vulnerability, please contact the project maintainers privately at:

 shervin.faramarzi_babadi@smail.th-koeln.de
 mayank_dinesh.mehta@smail.th-koeln.de

Please include a description of the vulnerability, steps to reproduce the issue, and any relevant technical information.

We will acknowledge vulnerability reports within 7 days.

We aim to investigate reported vulnerabilities and coordinate responsible disclosure within 30 days. The disclosure timeline may be extended if additional investigation or remediation is required.

Thank you for helping improve the security of this project.
